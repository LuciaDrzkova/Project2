Classic Marching Cubes triangle lookup table
--------------------------------------------
The file include/isa/McTables.h contains the classic 256-case Marching Cubes triangle lookup table in a generated C++ array. The table values were sourced from scikit-image's `CASESCLASSIC` lookup table:
https://github.com/scikit-image/scikit-image/blob/main/skimage/measure/_marching_cubes_lewiner_luts.py

PMP

PMP is fetched/linked as an external dependency and is not vendored here. See https://github.com/pmp-library/pmp-library for its MIT license and citation information.

PMP viewer dependencies
------------------------
The PMP viewer uses GLFW, Dear ImGui, GLAD, stb_image, stb_image_write and OpenGL. These dependencies are fetched or configured by PMP. See https://github.com/pmp-library/pmp-library and the corresponding upstream license notices for details.
